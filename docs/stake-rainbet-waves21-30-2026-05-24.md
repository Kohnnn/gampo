# Stake/Rainbet Waves 21–30 Close-out — 2026-05-24

+ `npm run build`. Final score: **122 tests across 26 files**, all green;
build clean ~9–15s; **82 procedural 16-bit WAV binaries** generated by
`scripts/genSfx.mjs`.

## Wave 21 — Titlebar popout + ChatDock stable

- `GameToolbar.jsx` — Game tools popover now portal-rendered to `document.body`
  with `position: fixed`, anchored under the trigger via
  `getBoundingClientRect`. Reposition listener for resize + scroll.
- Outside-click + Escape close behavior preserved; trigger excluded from
  outside-click hit test.
- ChatDock locked to a single 400px width across all tabs (`w-locked`).
  `width 0.18s ease` transition removed so switching tabs no longer
  visibly resizes the dock.
- Tab order reordered to **Stats / Progress / Chat / Race**.
- Default tab on first open is now `stats`.

## Wave 28 — Simulated player depth

- `SocialContext` rewritten with persona system:
  - 18 sim players across 6 personas (whale / analyst / gambler / cautious
    / streaker / mod), each with persona-tuned chat templates and tempo.
  - Whale tempo ~4.5s, mod tempo ~22s — so chat naturally varies.
  - 30% chance any player message triggers a 1.5–4s delayed reaction
    from a random sim player.
  - Race derived from personas — whales drift 4× faster, others scaled
    by index.
- Crash sim crowd grew from 8–12 to 10–16 players with persona-biased
  target/bet distributions:
  - 30% cautious (1.2–2.0×, $1–10 bets)
  - 50% mid (1.8–5.0×, $2–30)
  - 15% gambler (4–16×, $10–70)
  - 5% whale (12–52×, $50–300)

## Wave 29 — 16-bit SFX + audio bus + BGM

- `audioContext.js` rewritten with 3 gain nodes:
  - `masterGain` → `destination` (mute respects this)
  - `bgmGain` → `masterGain`
  - `sfxGain` → `masterGain`
- New `getVolumes()` / `setVolume(bus, value)` API. Volumes persist to
  `gampo:audio:volumes` localStorage.
- `useSfx.play()` now routes through `sfxGain` (graceful fallback to
  `masterGain` if not yet initialized).
- New `useBgm(skinFamily, mode)` hook with crossfade in/out (0.4–0.6s)
  through `bgmGain`. Module-scoped buffer cache, lazy decode.
- New `VolumeMixer.jsx` portal popover — Master / Music / Effects sliders
  (0–100%), mounted in `GameToolbar` Display group next to Mute.
- New `scripts/genSfx.mjs` — pure Node procedural 16-bit chiptune
  generator. No external deps. Outputs **44 SFX one-shots and 19 BGM
  loops** (8s, looped) into `public/audio/...`. Re-runnable + idempotent.
- `bgmManifest.js` and `sfxManifest.js` wired to the generated paths;
  cases / dice / mines / crash / plinko / keno / limbo / wheel / common
  buses now ship with 16-bit binaries.
- `SlotsGame.jsx` now plays per-skin BGM via `useBgm(config.skin, 'idle')`.
