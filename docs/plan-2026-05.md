# Plan — 2026-05 Stake/Rainbet 1:1 + GTO Poker

Owner: opencode session, started 2026-05-20.

## Goals

1. **Visual & UX parity with Stake/Rainbet** across all games.
2. **Real-time interactive GTO chart** in Live Poker (13×13 grid + frequencies + sizings + exploits), with the bot consuming the same data preflop.

## Plan A — UI/UX 6-batch rollout

- `RecentResultsStrip` — top-of-playfield latest-N pill row.
- `FairnessDrawer` — single shared drawer, reads `src/utils/fairRng.js`.
- `GameToolbar` — Sound · Reduce-motion · Fullscreen · Fairness · Help; mounted via `GameShell.titleBarExtras`.
- `BetMetaList` — payout/hit-chance/etc rows replacing inline `bp-bal-line` markup.

Edits:
- `BetPanel`: keyboard shortcuts (Space=Play, S=Stop, R=Rebet, +/−=adjust, H=Half, D=Double).
- `GameShell`: `titleBarExtras` defaults to `<GameToolbar/>`.
- 18 game JSX files: mount `<RecentResultsStrip>` at top of playfield.
- 17 game CSS files: `@media (max-width: 720px)` + `prefers-reduced-motion`.

### Batch 2 — Shell-game wiring fixes

- Thread `lastBet` for: Baccarat, Roulette, Sic Bo, Lottery, War, Video Poker, Tower, Chicken Cross.
- Snapshot `bets` for auto re-bet: Roulette, Baccarat, Sic Bo.

- `Math.random` → `nextRoll`: Baccarat shuffle, Casino War deck.
- Limbo gauge: real `target × instant` payout.

- Strip stale `console.log`: Mines, Dino.

### Batch 3 — Crash → shell

### Batch 4 — Mines → shell

### Batch 5 — Plinko & Dino → shell

### Batch 6 — Blackjack extract & antd unpin
Carve `BlackjackGame.jsx` out of the 2262-line `SimulatorGame.jsx`. Delete the 17 dead simulators. Unpin `antd` and `@ant-design/icons` from `package.json`.

## Plan B — GTO chart for Live Poker

Static preflop + static postflop textures (lazy-loaded JSON), tabbed sidebar **Chat | GTO | History**, bot preflop upgrade reading the same data.

### Engine touches
- `Game.js advanceStreet` — push `{type:'street', street}` history marker.
- `src/poker/util/positions.js` — `roleFor(seatIndex, buttonIndex, seatCount)`.
- `src/poker/util/handCanonicalize.js` — `canonical(['Ks','Qh']) → 'KQo'`.
- `src/poker/util/textureClassify.js` — board → texture key.
- `src/poker/gto/loader.js` — lazy `import()` of JSON.
- `src/poker/gto/lookup.js` — `(state, exploit?) → { grid, sizings, breakdown, advantages }`.

### UI
- `src/components/PokerGame/Sidebar.jsx` — tabbed sidebar.
- `src/components/PokerGame/GtoPanel.jsx` — context bar, street pills, 13×13 grid, sizings, breakdown, exploits.
- `src/components/PokerGame/HandHistoryTab.jsx` — sibling tab using `useGameSession('poker')`.

### Bot
`HeuristicBot.preflopStrength` → lookup against the same preflop JSON. Postflop stays Monte Carlo.

### Tests
`handCanonicalize`, `positions`, `textureClassify`, `gto/lookup` smokes.
