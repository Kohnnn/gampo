# Sportsbook Big-Match Benchmark Plan

## Goal

Reinforce the sportsbook so live provider quota is spent on famous, high-interest matches instead of broad low-signal fixture lists. The lobby should feel closer to an online sportsbook: marquee competition first, visual match spotlight, compact event rows, clear freshness/quota signals, and no client-side API keys.

## Approved Approach

Use a snapshot-first quota guard.

1. Keep a local marquee snapshot that can be generated by a crawler or edited manually.
2. Score competitions and teams before requesting or displaying odds.
3. Shortlist only big competitions such as FIFA World Cup, UEFA/Champions League, major domestic leagues, NBA/NFL playoffs/finals, UFC main cards, and Grand Slam tennis.
4. Filter provider results server-side and client-side so boring feed events do not dominate the lobby.
5. Add benchmark tests proving the guard caps visible live events and exposes spend metrics.

## Data Flow

```text
crawl/source material
  -> public/data/sportsbook-marquee.json
  -> server/sportsbookProviderProxy.js shortlist/filter
  -> src/sportsbook/freeFeedAdapters.js normalization
  -> src/sportsbook/sportsbookFeed.js final curation
  -> SportsHome visual spotlight + spend guard
```

The crawler is intentionally out of the runtime request path. Runtime refreshes read the snapshot and use provider APIs only for odds/prices.

## Benchmark Gates

- `0` provider keys in the browser bundle.
- Default live lobby is big-match-only.
- At least 80% of visible live events should match marquee competition/team keywords when live feed exists.
- Low-tier competitions are filtered out unless no marquee event is available.
- Provider payloads expose request/source counts and filtered/skipped counts for UI diagnostics.
- Cache remains server-side with the existing 5 minute TTL.

## UI Direction

- Add a matchday spotlight hero for the top marquee competition.
- Add a compact source/quota guard strip showing candidates, shown events, skipped events, and source freshness.
- Use visual team marks, live/soon urgency, and competition labels to make the page feel like a real sportsbook surface.
- Keep fake-credit wording and local settlement unchanged.

## Non-Goals

- No real-money wagering.
- No runtime scraping from the browser.
- No provider keys in `VITE_` variables.
- No copying Stake assets, CSS, icons, or team crests.
