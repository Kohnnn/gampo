# GamPo Documentation

GamPo is an educational, fake-credit casino and sportsbook simulator. The goal is to teach probability, RTP, expected value, volatility, hit frequency, bankroll risk, and sportsbook math. There is no cash value, no real-money flow, and no third-party brand assets.

## Index

- `architecture.md` - app structure, routing, state, RNG model.
- `lobby.md` - lobby rows, navigation, chat dock and race widget.
- `compliance.md` - what is and is not permitted in this simulator.
- `provably-fair.md` - seed/nonce model and the verify page.
- `roadmap.md` - deferred work, including code splitting.
- `changelog.md` - notable changes per pass.
- `games/originals.md` - originals games, math, RTP, payouts.
- `games/casino.md` - card and table games (blackjack, baccarat, roulette, war).
- `games/slots.md` - slots variants, themes, math model.
- `games/sportsbook.md` - fake-credit sportsbook, provider fallback, odds education, parlay/system math.

## Read this first

GamPo is for learning, not gambling. All credits are local-only. Do not deploy this app under any branding that implies real money, and do not import third-party licensed slot art, vendor logos, or operator brand identities.
