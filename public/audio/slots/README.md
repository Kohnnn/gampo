# Slot SFX assets

This folder contains clone-owned slot sound effects used by `sfxManifest.slots`.

## Files

- `spinStart.wav` - reel start
- `reelStop.wav` - per-reel stop
- `reelTick.wav` - reel tick / deceleration
- `anticipation.wav` - pre-stop anticipation
- `winLine.wav` - line or cluster win
- `scatter.wav` - scatter or bonus trigger
- `wheelLand.wav` - multiplier wheel land
- `holdFill.wav` - hold-and-respin tile fill
- `stickyLock.wav` - sticky wild lock
- `mysteryReveal.wav` - mystery symbol reveal
- `wantedSlam.wav` - wanted-poster slam
- `moneyCollect.wav` - collect / bonus close
- `cascadeStep.wav` - cascade tumble

## Provenance

- Source: locally generated procedural audio for GamPo.
- License: clone-owned project asset.
- Format: 16-bit PCM mono `.wav`, 44.1 kHz.

No third-party or externally licensed audio is ingested here.
